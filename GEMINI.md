# SimpleAE: ByteStorage — Правила и контекст проекта

## Описание проекта
**SimpleAE: ByteStorage** — упрощенный аналог Applied Energistics 2 (AE2) для Minecraft 1.20.1 (Forge):
- **Без лимита на типы предметов:** ячейки не имеют ограничения по количеству уникальных типов (Types). В одну ячейку можно поместить множество различных видов предметов.
- **Байтовая емкость:** расчет емкости производится по принципу **«1 предмет = 1 байт»**.
- Формула: `Занято байт = Суммарное количество всех предметов`.

## Правила генерации изображений
При генерации любых изображений, концепт-артов или рендеров для данного проекта:
1. **Детализированные текстуры поверхностей:** каждое изображение должно содержать реалистичные, осязаемые и проработанные текстуры (матовая шероховатость камня, шлифованный металл, микроцарапины, тактильные элементы управления, свечение индикаторов, глубина материалов и объем).
2. **Описание мода:** к каждому генерируемому изображению обязательно прикреплять краткое описание мода SimpleAE: ByteStorage (упрощенный аналог AE2 без типов предметов, где емкость ячеек рассчитывается по принципу «1 предмет = 1 байт»).
